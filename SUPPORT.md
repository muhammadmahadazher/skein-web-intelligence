# Support

- Read the [README](README.md) for installation and first-run guidance.
- Use the [runbook](RUNBOOK.md) for operational troubleshooting.
- Search [existing issues](https://github.com/muhammadmahadazher/skein-web-intelligence/issues).
- Open a [bug report](https://github.com/muhammadmahadazher/skein-web-intelligence/issues/new?template=bug_report.yml)
  when you can provide a reproducible problem.
- Start a [feature request](https://github.com/muhammadmahadazher/skein-web-intelligence/issues/new?template=feature_request.yml)
  for scoped product ideas.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not use a public
issue.
